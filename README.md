# Story Downloader Pro

تطبيق محلي بواجهة عربية RTL لتحليل روابط قصص Facebook العامة، وعرض عناصر القصة، وتنزيل كل صورة أو فيديو منفصلًا، أو تنزيل جميع العناصر في ملف ZIP واحد. دمج الفيديوهات متاح كخيار مستقل فقط عند وجود مقطعين أو أكثر.

## المزايا

- ربط Flask بالواجهة عبر API واضحة.
- اكتشاف الستوري المجزأة إلى عدة صور أو فيديوهات والتنقل بين أجزائها بالترتيب.
- إزالة معاملات الرابط التي تفرض عرض عنصر واحد مثل `view_single=1`.
- صفحة نتائج حقيقية تعرض الصور والفيديوهات المكتشفة بالترتيب.
- تحميل منفصل لكل عنصر.
- تحميل جميع العناصر في ملف ZIP.
- سجل محلي لعمليات التحليل والتنزيل.
- مجلد مستقل لكل عملية داخل `downloads/`.
- بيانات كل عملية محفوظة داخل `data/jobs/`.
- دمج الفيديوهات اختياري بواسطة FFmpeg.
- دعم `cookies.txt` للقصص التي تحتاج إلى جلسة Facebook صالحة.
- واجهة متجاوبة للحاسوب والهاتف.

## المتطلبات

- Python 3.10 أو أحدث.
- Chromium الخاص بـ Playwright لاكتشاف جميع أجزاء الستوري. يثبته `start.bat` تلقائيًا في أول تشغيل.
- FFmpeg فقط عند استخدام خيار دمج الفيديوهات.

## التشغيل على Windows

انقر مرتين على:

```text
start.bat
```

سيثبت الملف مكتبات Python ومتصفح Chromium الخاص بالفحص في التشغيل الأول، ثم يفتح التطبيق تلقائيًا.

أو شغّل يدويًا:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m playwright install chromium
python app.py
```

ثم افتح:

```text
http://127.0.0.1:5000
```

## كيف يكتشف الستوري المجزأة؟

1. يحاول التطبيق تحليل الرابط مباشرة بواسطة `yt-dlp`.
2. إذا عاد عنصر واحد فقط، يزيل `view_single=1` ومعاملات المشاركة من الرابط.
3. يفتح عارض Facebook داخل Chromium محلي.
4. يلتقط أكبر صورة أو فيديو ظاهر.
5. ينتقل إلى الجزء التالي ويكرر الالتقاط حتى نهاية الستوري أو تكرار العنصر.
6. تظهر جميع الأجزاء في الواجهة كبطاقات مستقلة مرتبة.

الحد الافتراضي هو 50 عنصرًا، ويمكن تغييره عبر:

```text
STORY_MAX_ITEMS=50
```

## cookies.txt

بعض قصص Facebook لا تسمح بالتحليل الكامل دون تسجيل الدخول، حتى لو كان رابط المشاركة يفتح عنصرًا واحدًا. في هذه الحالة صدّر cookies الخاصة بجلسة Facebook التي تملكها وضع الملف باسم:

```text
cookies.txt
```

في مجلد المشروع. يستخدم التطبيق الملف في متصفح الفحص وفي تنزيل ملفات الوسائط. يمكن أيضًا تحديد مسار مختلف عبر متغير البيئة:

```text
FACEBOOK_COOKIES_FILE=C:\path\to\cookies.txt
```

لا ترفع ملف `cookies.txt` إلى GitHub ولا تشاركه مع أي شخص.

## بنية المشروع

```text
app.py                         مسارات Flask وواجهات API
storage.py                     حفظ العمليات والسجل محليًا
extractor/facebook_story.py    تنسيق مسارات الاستخراج
extractor/browser_story.py     التنقل بين أجزاء الستوري والتقاطها
extractor/facebook_cookies.py  تحميل جلسة Facebook محليًا
downloader/                    تنزيل ملف واحد أو قائمة ملفات
merger/                        دمج الفيديوهات اختياريًا بواسطة FFmpeg
web/index.html                 الواجهة العربية
web/style.css                  التصميم المتجاوب
web/app.js                     ربط الواجهة بالـ API
data/jobs/                     بيانات العمليات المحلية
downloads/<job_id>/            ملفات كل عملية
```

## ملاحظات الاستخدام

- التطبيق مخصص للمحتوى العام أو المحتوى الذي تملك حق تنزيله.
- قصص Facebook المنتهية أو المحذوفة قد لا تكون قابلة للتحليل.
- إذا لم تظهر إلا قطعة واحدة رغم وجود عدة أجزاء، حدّث `cookies.txt` ثم أعد التحليل.
- Facebook يغيّر واجهته باستمرار؛ لذلك يوجد مسار مباشر بواسطة `yt-dlp`، ومسار متصفح للستوري المجزأة، ومسار احتياطي لبيانات Open Graph.
